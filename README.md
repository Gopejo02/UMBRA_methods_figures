# Time-dependent radiation thermo-chemical models for protoplanetary disks
**Authors:** Jorge Perez Gonzalez, Kees Dullemond, Myriam Benisty and Luke Keyte

---
In this repository you will find all the figures and movies presented in the paper. 

In the repository `abundance_maps_shadow` you will find `.mp4` files which 
show the time evolution of all the chemical species during the shadow in orbital 
time. In each movie, there are three phases. An initial equillibirum snapshot. 
Please pause the movie here if you want to see the equillibrium map. Then the 
disk will enter the shadow for half an orbit. The radiation field will restore after 
half an orbit and the disk will start heating up for another half.
